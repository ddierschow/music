# Symphony Number 1 in C -- Movement III, Scherzo

Written in 1855 by Georges Bizet.  Arranged for concert band from the original
orchestral score.

## Parts

- Flute 1 and 2
- Oboe
- Bassoon
- Clarinet 1, 2, and 3
- Bass Clarinet
- Alto Sax 1 and 2
- Tenor Sax
- Baritone Sax
- Trumpet 1, 2, and 3
- Horn 1 and 2
- Trombone 1, 2, and 3
- Baritone (bass clef and treble clef)
- Tuba
- String Bass
- Percussion 1 and 2, Mallets, Timpani

See [the Construction page for this repository](http://xocolatl.com/~dean/ly/common/construction.php).
